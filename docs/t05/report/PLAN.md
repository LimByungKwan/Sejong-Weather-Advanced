# T05 · 작업 전 고정 계획

## 개선 기능 한 개
세종 날씨의 마지막 정상 조회 시각 기준으로 최신값과 오래된 값을 표시한다.
30분 미만 최신값, 정확히 30분부터 오래된 값. 잘못된/미래 시각은 확인 필요.
실패 때 마지막 기온 유지, 새로운 성공 때 오류 해제·새 기온 표시.
화면을 유지해도 시간이 지나면 상태 갱신. DB와 날짜별 비교 규칙은 보존한다.

## 공통 사용 상한
각 30분 / 사용자 요청 각 10회.
시간은 최초 구현 요청 접수부터 종료·인계 응답까지의 경과시간, 대기 포함.
구현 지시·수정 지시 사용자 메시지 수를 세며 내부 도구 호출 수와 구분한다.
현재 ZIP 확인·고정 검사 작성은 구현 전 준비. 이 준비 커밋 직후 A 구현을 시작한다.
이번 ZIP 전달을 최초 구현 요청 1회로 기록하되 준비 종료 이후의 구현 시간도 별도로 기록한다.
상한 판정은 더 엄격하게 최초 접수 기준으로 한다.

## 공통 최초 요청
PLAN과 고정 검사 10개를 읽고 선언한 개선 한 개를 구현한다.
HANDOFF가 있으면 그 버전부터 이어간다. 상한을 지키고 기존 DB 동작을 보존한다.
같은 검사를 실행해 회차별 결과·실제 사용량을 기록한다. 한 개 이상 FAIL인 회차가 오류 1회다.
미실행은 미실행으로 표시한다. 종료 시 HANDOFF의 목표·현재 상태·실행 명령·통과 검사·남은 문제·다음 행동·건드리지 말 것 7항목을 남긴다.

## 증거 보존
A 시작→A 인계→B 시작→B 완료 순서와 각 시작·종료 커밋을 기록한다.
인수인계 SHA-256 동일성, 새 폴더 재현, 누락 수정 전후, 익명 측정표를 남긴다.
미측정값은 만들지 않고 재작업량도 수기로 입력하지 않는다.
전체 최종 인계 응답 시각은 사용자 화면에서 확인하여 보완한다.
