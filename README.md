# 세종 날씨 · 대화가 끊겨도 이어지는 프로젝트

기존 세종 날씨 프로젝트를 Import한 뒤, 두 AI가 저장소와 인수인계 문서만으로 작은 개선 하나를 이어서 완성했습니다. 첫 세션은 판정 로직과 인수인계를 남기고, 새 세션은 같은 검사를 재현한 뒤 자동 전환과 화면 연결을 마무리했습니다.

**[공개 비교 보고서 보기](https://t05-sejong-handoff-report-20261017.quannie70.chatgpt.site)** · [소스 저장소](https://github.com/LimByungKwan/Sejong-Weather-Advanced)

공개 결과물은 두 세션의 비교 보고서입니다. 개선한 날씨 앱은 로컬 환경에서 실행·확인했으며, 보고서 주소를 날씨 앱 배포 주소로 표시하지 않습니다.

## 개선한 기능

- 마지막 성공 조회 후 **30분 미만**은 `최신값`, **30분 이상**은 `오래된 값`으로 표시합니다.
- 새로고침이나 버튼 조작 없이 30분 경계에서 상태를 다시 판정합니다.
- 조회 실패 시 마지막 정상 기온과 조회 시각을 유지하고 실패 상태를 표시합니다.
- 재시도에 성공하면 기온·조회 시각을 갱신하고 정상 상태로 복구합니다.
- 잘못된 조회 시각이나 미래 시각은 `조회 시각 확인 필요`로 표시합니다.

## 작업 전 고정한 조건

구현 전에 입력과 관찰 가능한 기대값이 있는 검사 **정확히 10개**를 고정했습니다. 두 세션에 동일한 최초 요청과 검사, **30분·사용자 요청 10회** 상한을 적용했습니다. 요청 수는 사용자가 보낸 요청을 세며 내부 도구 실행 횟수와 구분합니다.

- [공통 최초 요청·시간 및 요청 상한](docs/t05/PLAN.md)
- [고정 검사 10개: ID·입력·기대값](docs/t05/fixed-tests.json)
- [고정 파일 원본 해시](docs/t05/frozen-hashes.json)

고정 검사의 삭제·완화·기대값 변경은 각각 **0건**입니다. Windows 줄바꿈 차이는 내용 동일 여부를 확인한 뒤 원본 바이트로 복원했으며 기대 해시를 바꾸지 않았습니다.

## 같은 검사 실행하기

Node.js 22.13 이상이 필요합니다. 저장소 루트에서 실행합니다.

```sh
node scripts/verify-t05-freeze.mjs
node --test tests/t05-fixed.test.mjs
node --test tests/replay.test.mjs tests/daily-comparison.test.mjs
```

원본 일치 안내, 고정 검사 `pass 10 / fail 0`, 기존 회귀 `pass 13 / fail 0`을 확인합니다.

앱 실행에는 pnpm 11.25.0과 로컬 DB 초기화가 필요합니다. 설치·빌드·DB 초기화·실행 순서는 [실행 안내](docs/t05/POST-B-VERIFICATION.md)에 있습니다. 타입 검사는 다음 명령으로 실행합니다.

```sh
pnpm exec tsc --noEmit --incremental false
```

Windows PowerShell에서는 `pnpm` 대신 `pnpm.cmd`를 사용하면 됩니다.

## 짧은 확인 방법 · 4줄

**위치:** 공개 비교 보고서의 측정표·고정 검사·인수인계와 위 고정 소스 링크로 이동합니다.

**행동:** ① 측정표 확인 → ② 고정 검사 10개 확인 → ③ 인계 원문·버전 링크 대조.

**통과 모습:** 같은 검사와 상한, 9/10→10/10 결과, 인계 7항목·동일 해시·시작→인계→재개→완료 순서가 확인됩니다.

**안 될 때:** 로그인 요구, 링크 오류, 검사 누락·기대값 변경, 해시 불일치 또는 실패 결과가 보입니다.

## AI와 나의 판단 · 3줄

**AI에게 맡긴 일:** GPT에 검사 10개와 인수인계 문서 작성을 맡기고, 클로드에는 남은 자동 전환 기능 구현을 맡겼다.

**직접 판단한 일:** 기존 세종 날씨 프로젝트를 바탕으로 개선하기로 정했고, 오프라인 실패·재시도 복구·30분 뒤 자동 전환은 직접 실행해서 확인했다.

**AI 제안을 따르지 않은 일:** GPT가 새로 만드는 방향을 제안했지만, 이전 작업을 이어가는 과제 취지에 맞게 기존 세종 날씨 저장소를 Import해서 진행했다.

**다음 도구 선택 기준:** 다음 작업도 익숙한 GPT로 먼저 시작하고, 고정 검사 통과 수·요청 수·인수인계 재현 결과를 보고 다른 도구로 이어갈지 판단하겠다.

## 공개 범위

공개 보고서에는 고정 검사, 집계 결과, 인수인계 문서와 본인 판단을 남깁니다. 대화 전문이나 비밀값은 포함하지 않습니다. 날씨 앱은 세종 대표 지점의 공개 날씨만 사용하고 개인 GPS를 수집하지 않습니다.
